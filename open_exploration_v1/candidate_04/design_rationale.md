# 04 · Field-notebook scene

**科学视觉命题。** 一个有身份的 Git Agent 角色读取历史“标本”，再让隔离的候选副本在工作场中改变。

**空间组织。** 克制插画角色在左中；唯一历史分枝沿其右上方铺开；可恢复 W4 像单张折角标本，右侧淡色椭圆是候选实验区。

**已核验论文图的迁移。** [Octo Fig.1](../../visual_research_v2/03_figure_gallery/octo_fig1_pdfp1.png) 的中心对象与轻插画识别；[RAP Fig.1](../../visual_research_v2/03_figure_gallery/rap_fig1_pdfp2.png) 的角色/状态/行动不同形态；[Voyager Fig.2](../../02_figures/voyager_fig2_pdfp2.png) 的具体工作对象。 这里只借主对象比例、状态对齐、边级展开或角色区分的原则；不照描源图的角色、配色组合与完整结构。

**图形语言。** 角色外形、折角 W4 标本和椭圆候选均为原创。角色只赋予 Git Agent；Router 仍是菱形，执行者是工具圆符号，版本仍为科学节点。

**技术连线。** v4 的橙线向下抵达候选边界外 Router；结果绿色提交 v7，v6 仍保持旧枝 HEAD。 折角历史 W4 完整地在椭圆外；椭圆内只有复制出的工作与更新。 Git Agent 到 v4 是 COMMIT；Router 独立在候选外；Fresh 仅淡化备选。

**纸宽检验与取舍。** [1063 px 预览](paper_width_preview.png)对应约 180 mm/150 dpi 的屏幕模拟；主要拓扑与工作变化可在缩小后看到，微型字段需要二次阅读。插画稍大时可能喧宾夺主；需要与师兄讨论小角色是帮助快速定位训练对象，还是削弱版本拓扑的严肃感。 纸张/标本只是工作状态的视觉隐喻，不声称实际存储在纸张或 notebook。
