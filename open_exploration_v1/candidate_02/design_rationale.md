# 02 · State metamorphosis

**科学视觉命题。** 第一眼看到同一工作产物如何改变：W4 被复制，Evaluation 变为 Evaluation'，Legacy API 从结果中消失。

**空间组织。** 上沿小型历史图确认祖先关系；中央巨大的工作片三态对齐形成实际科学主对象。Router 在候选边界上方，训练沿画面外缘返回 Git Agent。

**已核验论文图的迁移。** [VIMA Fig.1](../../visual_research_v2/03_figure_gallery/vima_fig1_pdfp2.png) 的同一物体跨状态对齐；[VAR Fig.2](../../visual_research_v2/03_figure_gallery/var_fig2_pdfp2.png) 的重复对象可见变化；[Voyager Fig.2](../../02_figures/voyager_fig2_pdfp2.png) 的中央真实工作产物。 这里只借主对象比例、状态对齐、边级展开或角色区分的原则；不照描源图的角色、配色组合与完整结构。

**图形语言。** W 状态用四条稳定槽位，不把每个动作做成相同方框。橙色更新和灰色删除与绿色保留空间对位。

**技术连线。** v4 经橙色控制线回到独立 Router，再由所选 Reuse & Patch 使 W4 发生 fork；绿色结果箭头提交 v7。 W4 在候选边界外且保留完整 Legacy API；W_t^0 和 W~_t 在内。 Router 是 Git Agent 输出 COMMIT 后的单独菱形；Fresh 是淡灰空状态替代路由。

**纸宽检验与取舍。** [1063 px 预览](paper_width_preview.png)对应约 180 mm/150 dpi 的屏幕模拟；主要拓扑与工作变化可在缩小后看到，微型字段需要二次阅读。历史图缩小后技术重点可能变成“如何改工作”而弱化“为何 v4 最优”；正式版需确认 v4/HEAD 的差异仍能第一眼被看到。 没有展开 INSPECT 每次读取内容的完整轨迹；只有必要的只读线与当前 COMMIT 记录。
