# AutoGen — repeated actor silhouette, dense overview caution

**核验。** [COLM 2024 OpenReview 记录](https://openreview.net/forum?id=BAakY1hNKS)；无法下载 OpenReview attachment，改用[arXiv 作者 PDF](https://arxiv.org/pdf/2308.08155)；本地版 [Fig. 1/PDF p1](../03_figure_gallery/autogen_fig1_pdfp1.png)、[680 px 预览](../03_figure_gallery/autogen_fig1_680px.png)。图注说明 conversational agents 可由 LLM、工具、人或组合构成，中部是对话任务，右部是不同应用；会议最终版图号未据此断言。

微型机器人/角色轮廓重复出现，在各应用中保持“agent”身份；对话气泡、工具小图标和用户形象在语法上分开，这比所有参与者都用矩形好。它的代价是局部区域太多，箭头和说明密集；缩到 680 px 时右侧小字与角色差异难辨。图标有实际身份作用，但整套拼贴式概览不适合 GitHarness。可借**一枚重复的、低细节的 Git Agent 符号**，再让训练回线准确落到该符号；不能复制 AutoGen 的角色画法、对话图式，也不能让 Git Agent、Router、Update Agent 长得完全一样——它们权责不同。
