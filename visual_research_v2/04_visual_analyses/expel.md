# ExpeL — v2 绘画语言复核

**核验。** [AAAI 2024 正式记录](https://ojs.aaai.org/index.php/AAAI/article/view/29936)；作者 PDF 的 [Fig. 1/PDF p3](../../02_figures/expel_fig1_pdfp3.png)、[680 px 预览](../../02_figures/expel_fig1_180mm96dpi.png)；完整首轮分析见[原记录](../../03_analysis/expel.md)。图号/页码只对应本地作者保存版。

图的左部承担宏观主线，右侧 A/B 解释被索引的局部处理；大小层级清楚，局部不是与主图平级的又一个架构。若遮住小字，箭头方向和信息交换仍可看出；小字密度在缩小后是弱点。图内角色与经验条目靠形态/颜色区分，不靠每个动作都包成相同矩形。对 GitHarness 的可迁移原则是**一张历史图 + 指向具体 v4 边的局部窗口**，并保持 v4 的视觉身份。ExpeL 的经验池可被整合/抽象，不能拿来暗示 GitHarness 原地修改历史 checkpoint；其 training/exploration 也不等于 Git Agent 的参数训练。
